Section 1

Introduction and Overview

Subul IN is an AI-powered professional productivity assistant designed to help users optimize their LinkedIn presence. The extension generates posts, evaluates profile quality, identifies skill gaps, and provides networking insights.

Subul IN is developed and operated by Smartovate Technologies ("Smartovate"), a Microsoft Partner. Subul IN is part of the broader Subul educational and professional development platform designed to support university students and early-career professionals.

The extension is integrated with the Subul ecosystem, an AI-powered educational and career development platform that helps university students improve employability, professional networking, and career readiness.

We adhere to the Principle of Least Privilege and collect only the data required to deliver these features. We do not sell your data and do not use it for advertising or profiling.

Subul IN does not sell personal data, does not display third-party advertising, and does not use collected data for advertising or marketing profiling.
Section 2

Data We Collect (Collection / Collecte)

Personal and authentication data
Email address, user name, and authentication tokens or session information retrieved from Subul-owned domains (https://*.subul.uk) to keep you signed in. Notification preferences if enabled.
LinkedIn profile data
Profile information visible to the user in their browser such as headline, work history, skills, certifications, education, and posts when you click Analyze, Scan, or Generate.
Networking analysis data
Profile information visible in the user's active browser tab used for user-requested networking compatibility analysis and professional recommendations.
Networking goals and preferences
Industries, seniority, and objectives you enter in settings to personalize scoring.
Technical and telemetry data
Endpoint status codes, request latency, and error types. We do not collect browsing history or device identifiers, and we do not use IP addresses for tracking or advertising.
All collection is user-initiated. The extension does not collect LinkedIn data in the background or while the user is not actively using the extension.

User control: The extension only activates analysis and AI features after a direct user action such as clicking Analyze, Generate, or Scan.

By using Subul IN features such as Analyze, Generate, or Scan, you consent to the processing described in this Privacy Policy.

By installing and using the extension, users explicitly consent to the collection and processing practices described in this Privacy Policy.

Subul IN accesses LinkedIn page content only while the user is actively viewing a LinkedIn page and only after a direct user action. The extension does not automatically collect profile data in the background.

The extension does not continuously monitor LinkedIn activity and does not collect LinkedIn profile data in the background without direct user interaction.

Telemetry use: Telemetry is used exclusively for reliability, debugging, abuse prevention, and service performance monitoring.

We do not collect LinkedIn passwords, private messages, payment data, or browsing history outside LinkedIn.
Section 3

How We Process Data (Processing / Traitement)

Legal basis: We process data based on user consent and our legitimate interest in providing the requested productivity and AI analysis features.

  • AI post generation: Your prompt and profile snapshot are sent via HTTPS to our backend, which securely proxies the request to Microsoft Azure OpenAI Service.
  • Profile scoring and gap analysis: Profile data selected by the user is analyzed locally in the browser whenever possible. Only the minimum profile content required for the requested analysis is transmitted to backend AI services.
  • Authentication relay: The extension retrieves authentication tokens or session information from Subul-owned domains (https://*.subul.uk) to keep the user signed in.

By triggering AI-powered features such as Analyze, Generate, or Scan, the user explicitly requests processing of the selected content through Subul IN backend services and Microsoft Azure OpenAI Service infrastructure.

AI requests are processed through Microsoft Azure OpenAI Service hosted by Microsoft. Data submitted through Microsoft Azure OpenAI Service is not used to train OpenAI or Microsoft foundation models.

AI prompts and generated content are retained only for as long as needed to deliver the request, support the user, investigate abuse, or meet legal and security obligations. Where they are no longer needed, they are deleted or de-identified according to our retention schedule.

Data minimization: We apply data minimization principles and transmit only the minimum data required to fulfill the requested feature.

AI prompts and generated content are not routinely reviewed by humans unless required for security investigations, abuse prevention, or user-requested support.

AI Model Training

Subul IN does not use your personal data, LinkedIn profile content, prompts, or generated outputs to train proprietary AI models.

Generated AI outputs may contain inaccuracies or incomplete recommendations and should be reviewed by users before professional use.

AI-generated scores and recommendations are informational only and are not used for automated employment decisions, eligibility determination, or legal profiling.

Section 4

Storage and Retention (Storage / Stockage)

Local storage
chrome.storage.local caches your profile snapshot and UI state. chrome.storage.sync stores limited authentication state and non-sensitive settings like server URL and language. Authentication state is time-limited and transmitted only over HTTPS.
Cloud storage
Data synced with the backend is stored in Microsoft Azure Cosmos DB. Encryption at rest uses AES-256.
In-transit security
All traffic uses TLS 1.2+ / HTTPS between the extension, backend, Cosmos DB, and Microsoft Azure OpenAI Service.

Local browser storage remains under the user's browser environment and may be cleared by the user at any time through browser settings.

Authentication tokens stored locally are time-limited session tokens and are not accessible to websites visited by the user.

Section 6

Chrome Extension Permissions

Subul IN requests the following permissions. Each permission is used only for its stated purpose.

Permission Purpose
storage Stores user preferences, cached profile data, consent flags, and authentication state.
activeTab Detects the currently active LinkedIn tab and accesses page content only after an explicit user action such as Analyze, Generate, or Scan.
scripting Injects the bundled analysis script into LinkedIn pages when activated by the user.
alarms Runs scheduled background tasks such as reminders or cache cleanup.
https://www.linkedin.com/*, https://linkedin.com/* Allows the extension to access LinkedIn page content rendered in the user's active browser tab for analysis.
https://*.subul.uk/* Retrieves authentication tokens or session information and syncs Subul learning data.
https://subulin-api.azurewebsites.net/* Connects to the Subul IN backend for AI analysis and data storage.
The extension does not request tabs, cookies, webRequest, history, or all_urls permissions.

Host permissions are limited to LinkedIn pages and Subul-owned domains required for the features you use.

Subul IN never accesses or stores LinkedIn login credentials, session cookies, or account passwords.
Subul IN does not perform automated scraping, bulk profile harvesting, background crawling, or autonomous interaction with LinkedIn. Analysis occurs only on pages actively opened and selected by the user.

Security Measures

  • HTTPS / TLS 1.2+: All API traffic is encrypted in transit.
  • Encryption at rest: Microsoft Azure Cosmos DB uses AES-256 at rest.
  • Access controls: Production access is restricted to authorized personnel only.
  • Incident response: We maintain procedures for detecting, investigating, and responding to security incidents affecting user data.
  • Token safety: Authentication tokens are stored using Chrome extension storage APIs and transmitted only over encrypted HTTPS connections.

No electronic transmission or storage method is completely secure, but we use reasonable measures to reduce risk.
